## 🛠️ CORE ENGINEERING & SECURITY SYSTEMS

### 1. `ShadowAuth` — Active Deception & Perimeter Threat Routing Platform
> **Architecture**: Perimeter Edge Reverse-Proxy & Threat Classifier  
> **Technologies**: `Python`, `FastAPI`, `Django`, `Docker`, `MySQL`, `RESTful APIs`

- **Dynamic Perimeter Ingress Inspection**: Profiles incoming network connections and request heuristics in real time at the edge.
- **Threat-Divergent Routing**: Transparently proxies authenticated, benign requests to actual production services while shunting malicious entities (vulnerability scanners, SQL injection payloads, automated exploit scripts, DDoS bots) to an isolated sandbox.
- **Honeynet Telemetry Capture**: Collects attacker IP intelligence, behavioral TTPs, and raw payload forensics inside an air-gapped honeypot environment without exposing core database clusters.

```
Incoming Request ──▶ [ Edge Profiler & Heuristic Filter ]
                          │
          ┌───────────────┴───────────────┐
          ▼ (Benign Traffic)              ▼ (Exploit / Scanner / Probe)
   [ Production APIs ]             [ Sandboxed Honeynet Node ]
   [ Core Data Stores ]            [ Telemetry & TTP Logging Engine ]
```

### 2. `AegisAppSec` — Autonomous DAST & Real-Time ASGI WAF Defense Platform
> **Architecture**: Application Security Testing (AST) & Real-Time Middleware Shield  
> **Technologies**: `Python`, `FastAPI`, `Django REST Framework`, `ASGI Middleware`, `Docker`

- **Automated DAST Vulnerability Engine**: Lightweight dynamic application security testing tool executing black-box scans across HTTP/REST endpoints for OWASP Top 10 vulnerabilities (SQLi, IDOR, SSRF, XSS).
- **Zero-Latency ASGI WAF Filter**: Middleware layer intercepting inbound HTTP requests directly on the ASGI event loop, neutralizing suspicious serialization formats and header injections before route dispatch.
- **Exploit Reproduction Engine**: Generates reproducible PoC scripts with verified remediation recommendations for developers.
