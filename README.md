## 🚀 Featured Engineering & Security Projects

### 🛡️ [ShadowAuth](https://github.com/Amankumarx1) — Active Deception & Threat Routing Platform
> *Enterprise-grade network security architecture built on active deception and intelligent honeynet routing.*
- **Edge Traffic Profiling**: Inspects real-time ingress traffic, routing benign users to production APIs and seamlessly diverting malicious actors (scanners, SQLi, DDoS bots) to an isolated sandbox.
- **Honeypot Sandbox Architecture**: Captures payload telemetry, adversary TTPs, and attacker fingerprints without endangering production systems.
- **Tech Stack**: `Python`, `FastAPI`, `Django`, `Docker`, `MySQL`, `REST APIs`, `Reverse Proxy Routing`

---

### 🔍 [AegisAppSec](https://github.com/Amankumarx1) — Autonomous DAST & Real-Time WAF Defense Platform
> *All-in-one vulnerability assessment and dynamic application security enforcement hub.*
- **Automated DAST Engine**: Lightweight dynamic analyzer scanning endpoints for OWASP Top 10 vulnerabilities.
- **Real-Time ASGI WAF Middleware**: Low-latency request filtering blocking malicious payloads before touching business logic.
- **Exploit Reproduction Engine**: Interactive sandbox assisting security engineers with automated PoC verification and remediation guidance.
- **Tech Stack**: `Python`, `FastAPI`, `Django REST Framework`, `JavaScript`, `Docker Containers`

---

### 🔎 [LeakLens](https://github.com/Amankumarx1/Leaklens) — Authorized Data Exposure Detection & Response
> *Proactive scanning and threat intelligence tool for identifying leaked credentials, API tokens, and sensitive data.*
- Real-time exposure classification, risk rating, and automated incident triage.
- Built with modular threat-detection rules and security workflow automation.
- **Tech Stack**: `Node.js`, `TypeScript`, `React`, `Security Auditing APIs`

---

### 🌐 [DualSurf](https://github.com/Amankumarx1/dualsurf) — Dual-Mode Cyber Browser & Security Orchestration
> *Dual-engine secure browser platform engineered for cyber research, isolation, and controlled malware inspection.*
- Isolates untrusted internet traffic into compartmentalized environments while maintaining native user workflow.
- **Tech Stack**: `Python`, `Containerization`, `Security Sandboxing`

---

### 💻 [RootSec-V3 Platform](https://rootsec-v3.vercel.app/) — Cyber Club & Knowledge Portal
> *Official web platform for RootSec, Chandigarh University's premier cybersecurity student organization.*
- Interactive modern interface delivering CTF resources, student guides, workshop schedules, and project showcases.
- **Tech Stack**: `HTML5`, `CSS3`, `Vanilla JavaScript`, `Vercel Engine` • **Live**: [rootsec-v3.vercel.app](https://rootsec-v3.vercel.app/)

### 📍 [Indoor Positioning System (IPS)](https://github.com/Amankumarx1/IPS-IndoorPositioiningSystem) — Autonomous Indoor Navigation
